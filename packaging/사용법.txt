로또 번호 분석 프로그램 - 사용법

1. 이 폴더 전체를 바탕화면이나 문서 폴더처럼 쓰기 가능한 곳에 둡니다.
   (폴더 안의 파일을 따로 빼내면 실행되지 않습니다. Program Files 안에서는 동작하지 않습니다)
2. LottoAnalyzer.exe 를 더블클릭합니다.
3. 검은 창이 뜨고, 잠시 뒤 브라우저에 화면이 열립니다.
   방문 기록이 남지 않는 창(Edge InPrivate, 없으면 Chrome 시크릿)으로 열립니다.
   열리지 않으면 검은 창에 적힌 주소를 브라우저 주소창에 직접 입력하세요.
4. 화면에서 아래 과정이 자동으로 진행됩니다. 엑셀 파일을 따로 준비할 필요가 없습니다.
   - 처음 실행: 공식 사이트에서 1회차부터 당첨 데이터를 받아 data 폴더에 엑셀을 만듭니다 (2~5분).
   - 다음부터: 새로 추첨된 회차만 받아 추가합니다.
   - 분석, 백테스트를 거쳐 다음 회차 후보 숫자 10개를 보여 줍니다(모델 점수 상위 10개).
   - 후보 카드의 "번호 재산출"을 누르면 분석을 다시 하지 않고 다른 규칙으로 후보 10개만 새로 고릅니다.
     모델 점수 상위 5개 + 최근 5회 당첨번호 중 무작위 2개 + 최근 50회에 가장 많이 나온 쪽 1개와
     가장 적게 나온 쪽 2개입니다. 자세한 정의는 화면에 있습니다.
5. 끝내려면 검은 창을 닫습니다.

인터넷 연결이 필요합니다. 연결이 안 되면 이전에 받아 둔 데이터로만 분석합니다.
data 폴더에 당첨번호 엑셀(lotto.xlsx), 백테스트 결과(backtest.xlsx), 백업(backup 폴더)이 저장됩니다.
새 버전으로 바꿀 때는 data 폴더를 지우지 말고 나머지 파일만 덮어쓰세요.
lotto.xlsx를 Excel로 열어 둔 채 실행하면 저장하지 못하니 닫고 실행하세요.

처음 실행할 때 "Windows의 PC 보호" 창이 뜨면
"추가 정보"를 누른 뒤 "실행"을 누르세요. (서명이 없는 프로그램에 뜨는 안내입니다)
받은 zip이 전달한 사람이 만든 것과 같은지 확인하려면, zip이 있는 폴더에서 PowerShell을 열고
  Get-FileHash LottoAnalyzer.zip
를 실행한 뒤 나온 Hash 값을 전달한 사람이 따로 알려 준 SHA-256 값과 비교하세요. 다르면 실행하지 말고 다시 받으세요.

후보 숫자 10개는 로또 한 게임(6개)이 아니라 후보 목록입니다.
이 프로그램은 당첨을 보장하지 않습니다. 두 방식의 성능이 무작위 선택과 차이가 있는지는 화면의 백테스트 판정에서 확인합니다.
지금까지의 측정에서는 두 방식 모두 의미 있는 차이가 없었습니다.
첫 화면 후보는 같은 데이터면 같고, 번호 재산출의 후보는 누를 때마다 일부 자리가 바뀝니다.
후보에 직전 회차 번호가 여러 개 들어 있어도 근거가 아닙니다. 각 번호의 실제 당첨 확률은 6/45로 모두 같습니다.
